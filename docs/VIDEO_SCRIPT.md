# Demo video script (about 2 minutes)

The video is optional for the Data Bowl, but judges often watch it before opening the link. Record the screen at 1280×800 with the live site open. Speak slowly; each block is roughly the time shown.

**0:00–0:12 — Hook (Predict view)**
"Every week a badminton coach asks: how strong is the next opponent, and why? Squadro Match Lab answers that for any match on the BWF World Tour, using a model audited on more than ten thousand matches it never saw."

**0:12–0:40 — Predict**
Show Shi Yu Qi against Kunlavut Vitidsarn.
"The model gives Shi Yu Qi 59 percent. More useful is the why: head-to-head is 5–1 his way, his rating is slightly higher, but Kunlavut's experience pulls the other way. Each factor shows how far the probability would move without it, so a coach can argue with the number."

**0:40–0:58 — Live after game 1**
Type 17–21 (side A loses game 1). Press Update.
"Once game 1 is in, the forecast updates. On all of 2026, this lifts ROC-AUC from 0.80 to 0.90."

**0:58–1:18 — Draw odds**
Switch to Draw odds, women's singles, press Shuffle twice.
"Here are exact title odds for a 16-player draw. An Se Young is 75 percent from a seeded draw. Shuffle it, and the draw-luck panel shows how much the draw alone can move each contender."

**1:18–1:40 — Insights**
Scroll the six findings.
"From 10,852 unseen matches: home players beat the model by about three points. Coming off a three-game match costs about three points next round. Men's singles is the hardest event to call, and upsets peak in finals. Each finding ends with what a coach should do about it."

**1:40–1:55 — Evidence**
"And you can check all of it. The model was frozen before 2025. This page shows its audit, its calibration, where it is weak, and a live test proving the browser reproduces the original Python model to 16 decimal places."

**1:55–2:05 — Close**
"Squadro Match Lab: audited, explainable badminton analytics that runs on a phone. Thanks for watching."
